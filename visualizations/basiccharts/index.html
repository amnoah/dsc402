Project 1: Basic Charts

For our initial project, I chose to utilize the ".nyc Domain Registrations by Zip Code" dataset, which provided statistics on how many ".nyc" domains were registered in each New York City zipcode as of October 7, 2025.

The only processing I applied to the data itself was to combine values by borough instead of zip code. This means that the data refers to the amount of domains registered in Manhattan, Bronx, Queens, Brooklyn, or Staten Island rather than the amount registered in a given zipcode.

Charts

Initial Chart

This initial chart is a basic bar chart comparison of the data. It's incredibly easy to understand, but it is basic and doesn't allow for deep insight.

Chart Revision 2

This version of the chart adds amount numbers and makes it so you can hover over the bars for info break downs. This makes it more accessible and precise, allowing users to make true data comparisons.

Chart Revision 3

This version of the chart adds multiple colors to make it visually distinct/interesting, and it adds comparison lines. This makes it easier for the chart to catch someone's eye, and it makes it so that visual comparisons are still viable for the smaller values.

Chart Revision 4

Lastly, this flips the data horizontally. I think this makes it more intuitive to see how much more the data for Manhattan is than the others. That may be because I'm on a laptop, but it seems to fit my device screen better and is more easily interactive.
